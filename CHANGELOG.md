# Changelog

## v0.1.0 — Public Beta (2026-06-03)

- **Release status:** this is the first public-beta release snapshot of the repository.
- **Offline release preflight:** repository docs and tests now document and enforce
  a docs-first, offline-safe public-readiness check for release hygiene.
- **Safety posture:** maintain provider and platform safety boundaries; public
  contribution and runtime documentation continues to state that runtime safety
  checks must not be weakened.
- **Credential redaction:** documentation now emphasizes no sharing of API keys,
  tokens, or credentials and that any logged or surfaced runtime data must be
  redacted.
- **Gateway/service operations:** this changelog intentionally excludes operational
  command playbooks for restarting/reloading Gateway services.
